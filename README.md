# Shriya Kotala | Personal Portfolio

![Live Status](https://img.shields.io/badge/Status-Live-brightgreen)

A highly interactive, Spider-Verse inspired personal portfolio showcasing my journey and projects across Software Development and AI/Machine Learning Engineering.

Live Application: [shriya-kotala-portfolio.vercel.app](https://shriya-kotala-portfolio.vercel.app/)

---

## Key Features

- Comic-Book Aesthetics: Custom halftone background patterns, dynamic glassmorphism panels, and bold typography
- Interactive Persona: Fully custom-coded animated SVG character as the focal point of the introduction
- Dynamic Theming: Seamless Neon Noir Dark Mode and Light Mode toggling with fully inverted high-contrast UI states
- Performance Optimized: Heavily optimized React component for instant load times and fluid scroll animations
- Seamless Contact Routing: Frictionless contact form utilizing deep-linked webmail routing

---

## Tech Stack

- Framework: Next.js (React)
- Styling: Custom Vanilla CSS (CSS Variables, Keyframe Animations, Backdrop Filters)
- Deployment: Vercel

---

## Running Locally

1. Clone the repository:
```bash
git clone https://github.com/shriya-1603/ShriyaKotala_portfolio.git
```

2. Navigate into the directory:
```bash
cd ShriyaKotala_portfolio
```

3. Install dependencies:
```bash
pnpm install
```

4. Start the development server:
```bash
pnpm run dev
```

5. View the application at http://localhost:3000
